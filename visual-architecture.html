TQ ChatBot #1 — System Architecture

Visual flow from client website through AI, scoring, storage, automation, and output

1. Client Website
Landing page with hero, features, and floating chat widget toggle
2. Embedded Chat Widget
Modal overlay chat interface. Creates visitor_id in localStorage, starts chat_session.
3. Conversation Engine
Drives qualification flow: greeting → questions → contact capture → routing. Collects signals from user input.
4. Claude Extraction (Optional)
LLM extracts structured signals (has_business, urgency, problem_clarity) from natural language. Falls back to deterministic regex.
5. Deterministic Scoring
scoreLead() applies rule-based scoring: high/medium/low → calendly/nurture/guidance. Single source of truth. Fully auditable.
6. Supabase (Persistence)
Stores leads, sessions, messages, events, signals. RLS for multi-tenant isolation. Dashboard queries.
7. n8n (Automation)
Receives events via Edge Function. Triggers alerts, CRM sync, follow-up sequences, booking notifications.
8. Calendly / Alerts / Dashboard
High leads → Calendly booking. Alerts → Slack/email. Dashboard → real-time analytics (scores, funnel, conversations).
